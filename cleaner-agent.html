Excel Data Cleaner Agent

Paste comma separated rows (first row = headers) or load a CSV. The agent trims spaces, fixes name case, standardises dates to YYYY-MM-DD, removes blank rows and duplicates, and reports what it changed. Sample messy data is filled in.

Demonstration only. Dates written as dd/mm/yyyy are assumed day first. Always compare with the original file.
